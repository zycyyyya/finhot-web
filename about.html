关于 finhot

finhot 是一个面向保险运营、二级市场投教和私募销售运营从业者的精选资讯聚合平台。 每日自动从多个公开信源采集行业动态，通过来源分层、AI 证据化分析、三场景独立适配度评分、 近似标题去重与双层业务筛选，为不同业务角色快速定位最有价值的资讯。

业务场景导航

首页按三个业务场景组织资讯，每条资讯拥有唯一主场景，其余仅作辅助提示：

保险运营：保险、险企、寿险、财险、健康险、养老、年金、费率、偿付能力、保费、理赔等
私募销售运营：私募、量化、对冲、FOF、净值、回撤、仓位、策略、募集、备案、托管等
二级市场投教：A股、港股、美股、指数、ETF、债券、央行、货币政策、估值、财报、宏观数据等

一级导航之外提供二级内容属性筛选：官方监管、产品动态、行业动态、深度研究、快讯、观点、仅看权威源。 当前无匹配结果的标签会自动隐藏。

信源声明

finhot 将信源分为四层：S0 权威原始源、S1 结构化数据源、S2 专业财经媒体、S3 快讯/观点线索。 监管、公告、产品类信息优先参考原始出处；媒体与快讯主要用于发现线索和补充背景。

S0 原始源 中国证监会 政策发布、执法公告、征求意见（行政类公告已过滤）
S0 原始源 深圳证券交易所 监管措施、处罚公告（上市/退市类行政公告已过滤）
S2 媒体 财新网 深度财经报道、行业分析、独家调查
S2 媒体 华尔街见闻 全球宏观、金融市场、实时快讯
S2 媒体 第一财经 财经快讯、市场数据、公司新闻
S2 媒体 英为财情 Investing.com 股市资讯、技术分析
S2 媒体 财联社（深度） 深度报道、市场解读
S3 线索 36氪 / 财联社快讯 科技快讯、行业观点、市场线索
从业价值分由六项组成：行业相关性 25 分、来源权威性 20 分、业务影响 20 分、时效性 15 分、内容深度 10 分、可行动性 10 分。 S3 快讯源单条最高不超过 75 分；涉及监管、处罚、法规、批复的媒体转述最高不超过 82 分，优先等待或补充原始出处。 三场景评分各为 0-100 的独立适配度，综合考虑关键词命中、来源权威性和业务影响； 今日精选按保险 6 条、私募 7 条、投教 11 条的场景配额选出 24 条，确保各业务方向内容不偏空。

使用与合规边界

重要提示：finhot 仅提供公开信息聚合、分类、评分与 AI 辅助摘要，不构成任何投资建议、资产配置建议、保险产品推荐、收益预测或收益承诺。任何决策均应以监管机构、交易所、发行人及原始发布方的正式披露为准，并结合自身风险承受能力独立判断。
私募基金相关内容仅供合格投资者与金融从业人员进行内部研究和投教参考，不构成面向不特定对象的宣传推介、公开募集或产品销售。
AI 生成内容可能存在遗漏、误判或过度概括；页面中的“原文依据”用于追溯，不代表系统已独立核实全部事实或确认因果关系。
资讯标题、摘要及链接的相关权利归原发布者所有；本站不替代原文，不对第三方内容的完整性和持续可访问性作保证。
发现事实、来源、版权或分类问题，可通过 GitHub Issues 提交纠错，处理时将优先核对原始出处。
页面日期与自动任务按北京时间口径展示；每条资讯保留发布时间、抓取时间、来源层级和证据链接，缺失发布时间时不冒充当日资讯。
宏观看板数值仅供宏观环境参考，以官方机构正式公布为准；自动刷新失败时展示最近一次有效值并保留原日期，不用推断值填补。

技术说明

本站为静态站点，数据由 finhot-web 仓库内置的 Node.js 引擎自动采集聚合，每日分时自动更新； finhot 独立仓库则提供供 Agent 调用的资讯查询 Skill 与可选 Python 离线工具。 自动流程包含协议与字段校验、稳定资讯 ID、去重、三场景适配度评分、事件聚类及 AI 证据引用校验。 所有外部内容链接均指向原始出处；涉及重要事实时，应打开“原文依据”核对完整上下文。

数据采集: RSSHub 多实例容错 + Investing.com 直采，单源默认 30 条、触顶自适应至 50 条并持续监控，前台保留 7 天精选资讯
精选评分: 通用从业价值分 + 保险运营/二级市场投教/私募销售三套独立适配度评分，范围 0-100
历史关联: 前台维持轻量展示，后台独立保存最多 5,000 条、90 天的历史证据，并持久化事件 ID 追踪跨日进展
AI 分析: SenseNova DeepSeek-v4-Flash 生成辅助摘要；所有输出经结构、枚举、长度及原文证据 ID 校验，异常时回退规则分析
自动监控: 对连续失败、覆盖率过低、数据陈旧、主运行 AI 回退、连续触顶和调度延迟进行告警，GitHub Issue 自动去重
宏观看板: 日报顶部常驻宏观参考看板；LPR（中国货币网）、美债收益率（美国财政部）、汇率（ECB 参考）、现货黄金每日随管线自动刷新并做数值合理性校验，10年期国债、存款利率、联邦基金利率为人工核实值并逐项标注来源与日期
更新频率: 北京时间 08:15 主运行，并在 12:17、16:19、20:21 增加错峰保底运行
部署方式: 纯静态站点 + GitHub Pages
